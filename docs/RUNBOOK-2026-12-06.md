  next to it. Do not improvise.

CST) has logged `Backup uploaded`.

**3b. Copy the existing backups into `prod/`.** This uses a one-off container
on the new env and the new key.

What gets copied:
- every current `dev-test/db-*.sql.age` **except** Apr 26, and
- the Apr 26 **163628** copy from `keep/dev-test/` as April's representative,
  which is what the fixed retention keeps.

Copies go **oldest first**. A copy's LastModified is the copy time, and the
staleness canary picks the newest by LastModified. Key names are unchanged,
so retention, which reads dates from key names, carries over.

```sh
$C run --rm --no-deps -T web python manage.py shell <<'PY' 2>&1 | grep -vE 'AXES|objects imported'
from books.core.backup.storage import B2Config, B2Storage
cfg = B2Config.from_env()
assert cfg.prefix == "prod/", cfg.prefix
c, B = B2Storage(cfg)._client, cfg.bucket
def listing(prefix):
    out = []
    for page in c.get_paginator("list_objects_v2").paginate(Bucket=B, Prefix=prefix):
        out += page.get("Contents", [])
    return out
pairs = [(o["Key"], "prod/" + o["Key"][len("dev-test/"):], o["Size"], o["ETag"])
         for o in listing("dev-test/db-")
         if o["Key"].endswith(".sql.age") and not o["Key"].startswith("dev-test/db-2026-04-26-")]
k = c.head_object(Bucket=B, Key="keep/dev-test/db-2026-04-26-163628.sql.age")
pairs.append(("keep/dev-test/db-2026-04-26-163628.sql.age", "prod/db-2026-04-26-163628.sql.age", k["ContentLength"], k["ETag"]))
pairs.sort(key=lambda p: p[1])
have = {o["Key"] for o in listing("prod/")}
for src, dst, size, etag in pairs:
    if dst in have:
        print("SKIP (exists)", dst); continue
    c.copy_object(Bucket=B, Key=dst, CopySource={"Bucket": B, "Key": src})
    h = c.head_object(Bucket=B, Key=dst)
    print("COPIED" if (h["ContentLength"] == size and h["ETag"] == etag) else "MISMATCH", src, "->", dst, size)
print("sources:", len(pairs), "prod/ objects now:", len(listing("prod/")))
PY
DRY_RUN=1 PREFIX_OVERRIDE=prod/ /usr/local/bin/backup-staleness-canary.sh; echo "rc=$?"
```

**Expect:**
- Every line says `COPIED`, never `MISMATCH`.
- 18 sources: Nov 21 (2: 034426 and 093708), Nov 22 – Dec 6 (15), plus Apr 26 163628.
- The prod/ count equals the sources count.
- The dry run gives rc=0 `HEALTHY` with prefix `'prod/'`, the newest being
  today's `db-2026-12-06-…`, and no `DISAGREE` note.
